# Blackpoint Cyber

> Blackpoint Cyber is a cybersecurity company (Accel-backed) whose CompassOne platform unifies managed detection and response (MDR), identity threat detection and response (ITDR), and security posture management, backed by a 24/7 human-led, AI-powered SOC. This profile is maintained by API Evangelist as part of the APIs.io network; the CompassOne product API (api.blackpointcyber.com) is gated behind Auth0 identity and API keys, so most machine-readable artifacts here are derived from Blackpoint's public identity, security, and compliance surface rather than a public OpenAPI.
